04 · what it does

Small app. Big ears.

01

ctrlwinquick

ctrlshiftwinlong

Two ways to talk.

Quick notes or long dictation, each on its own hotkey. Hold to talk, or switch to toggle.

02

Long dictation stays light.

Long recordings spool to a temporary file and are transcribed in chunks, so memory use stays flat. The audio is deleted when the session ends.

03

clipboard→active window→restored

Pasted where you were.

Eve copies the text, pastes it into the active window, and can then restore your previous clipboard.

04

raw dictationclean promptcodex promptmessage rewritecommand mode

Raw, or tidied up.

Paste exactly what you said with Raw Dictation, or let another output style tidy it with local, rule-based cleanup first.

06

Faster-Whisper, your pick.

large-v3-turbo is recommended (about 1.5 GB), large-v3 (about 2.9 GB) is for maximum accuracy, and small (about 0.5 GB) suits lighter hardware. The current model keeps working while a new one downloads.

07

cpugpu · cuda pack

CPU first. GPU optional.

Eve works on the CPU. An optional NVIDIA CUDA pack, downloaded separately (about 495 MB) and verified by hash, speeds up transcription on supported GPUs.

05 · privacy

Your audio stays on your computer. No account. No telemetry.

Speech recognition runs in a local service bundled with the app. Audio and transcripts are never uploaded.

Three steps. Then talk.

    download

    Eve.Web.Setup.<version>.exe from GitHub Releases.

    The small web installer downloads the app during setup, so stay online. It is unsigned, so Windows SmartScreen may ask you to confirm.

07 · faq

Questions, answered plainly.

Does Eve process speech locally?

Yes. In the packaged app, speech recognition runs in a local service on your machine, and audio and transcripts are never uploaded. Eve still needs the network for downloads: the web installer payload, the speech model on first use, and the optional GPU pack if you install it.

What data does Eve keep, and where?

There is no account and no telemetry. History and Insights live in a local SQLite database, normally under %APPDATA%\Eve. Long-dictation audio is temporary and is never written to History or logs. Copied diagnostics exclude logs, file paths, History, and transcript text, but review any report before you share it.

Do I need an NVIDIA GPU?

No. Eve runs on the CPU. The optional NVIDIA CUDA pack is a separate download of about 495 MB (about 771 MB installed), verified by hash, that you install from Settings. It needs a supported driver and enough GPU memory, and it has not been shown to work on every NVIDIA machine.

Why does Windows SmartScreen warn about the installer?

The Eve installer is unsigned, so Windows SmartScreen may ask you to confirm before it runs. Download it only from the project's GitHub Releases page. Each release publishes SHA256SUMS.txt and SHA512SUMS.txt so you can check the files.

What are the system requirements?

Windows 10 or 11 on x86-64, at least 4 GB of RAM (8 GB or more recommended), and an internet connection for the web installer and the first model download. A September 2026 build candidate measured about 686 MB unpacked; allow more space for speech models and the optional GPU pack. The Microsoft Visual C++ Redistributable is required, and Eve links to the official installer when it is missing.

Does Eve type into my app while I am still speaking?

No. The small pill shows a timer and status, not a transcript. After you stop, Eve transcribes and pastes the text into the active window once. It can then restore your previous clipboard.

Is Eve ready for everyday use?

Eve v0.8.2-alpha.9 is an alpha pre-release, so expect rough edges. Its release notes say that automated tests and synthetic overlay checks do not establish real microphone dictation acceptance or clean-machine installer lifecycle acceptance. Eve is free and MIT licensed.
